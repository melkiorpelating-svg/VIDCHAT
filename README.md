# 📹 VIDCHAT — Temukan & Ngobrol Langsung

> **Video Chat • Teks • Pilih Negara • Tanpa Daftar • 100% Gratis**

VIDCHAT adalah aplikasi video chat yang mirip dengan OmeTV — langsung pakai, tidak perlu daftar, tidak perlu akun! 🎉

---

## ✨ FITUR
- 📹 Video Chat Real-time
- 💬 Teks Chat Langsung
- 🌍 Pilih Negara
- ⏭️ Lewati / Ganti Pasangan
- 🔇 Matikan Suara / 📷 Matikan Kamera
- 📱 Tampilan HP & Desktop
- 🔒 Tanpa Daftar — Langsung Masuk!
- 🆓 100% Gratis — Tanpa Iklan Berlebih

---

## 🚀 CARA PAKAI
1. Buka file **`index.html`** di browser
2. Izinkan **Kamera & Mikrofon**
3. Tekan **▶️ MULAI** → otomatis terhubung
4. Ngobrol via Video atau Teks 💬
5. Tekan **⏭️** untuk ganti orang
6. Tekan **⏹** untuk berhenti
